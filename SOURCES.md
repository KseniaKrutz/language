# Источники данных и методов

- Leipzig Corpora Collection: https://wortschatz.uni-leipzig.de/en/download
- Leipzig corpus format: https://www.wortschatz.uni-leipzig.de/documents/Format_Download_File-eng.pdf
- Metadata index and loader description: https://huggingface.co/datasets/imvladikon/leipzig_corpora_collection
- Universal Dependencies: https://universaldependencies.org/
- Universal Dependencies downloads: https://universaldependencies.org/download.html
- SentencePiece repository: https://github.com/google/sentencepiece
- SentencePiece training options: https://google.github.io/sentencepiece/doc/options/
- SentencePiece sampling API: https://google.github.io/sentencepiece/doc/cpp/

The Leipzig metadata mirror is used only to discover corpus IDs and source URLs. The actual archives are downloaded from the Leipzig server. Check the terms of use and license for each corpus before redistributing any material.
